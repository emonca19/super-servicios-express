Account microfrontend

- `account-dashboard.component.js` — Componente principal del dashboard de cuenta.
- `index.js` — barrel para exportaciones del microfrontend.
- `logic.js` — lugar para helpers puros (a añadir si es necesario).

Consejo: Mantén cualquier llamada a la API en `services/` y lógica de presentación en `logic.js`.
